Разделение комнат

Для разделения выбери комнату: на ней появится линия, перетащи её концы на место. Перед применением проверь параметры.

Пороги и рампы
Зелёная линия — проходимый порог, красная — непроходимый. Нажми на порог на карте, чтобы двигать его концы, или добавь новый.
Запреты и стены
Красная линия — виртуальная стена, красный прямоугольник — запретная зона, синий — зона без влажной уборки, тёмная шахматка — ковёр (найденный роботом — светлее, добавленный — темнее и с рамкой), серый пунктир — место, где найденный ковёр не учитывается. Нажми на фигуру на карте: её можно двигать, тянуть за уголок ↘ (стену — за концы) и удалить крестиком. Изменения уходят на робот только по кнопке «Сохранить изменения».
Ковры
Добавленный ковёр — тёмная шахматка с рамкой, серый пунктир — место, где найденный роботом ковёр не учитывается. Ниже — тип и уборка ковров, которые нашёл робот.
Найденные ковры: тип и уборка
Уборка по комнатам
Робот применяет их, когда в «Все настройки пылесоса» включена «Индивидуальная уборка».
Порядок уборки
Робот убирает комнаты в этом порядке при уборке всего дома.
Типы комнат и пол
Тип задаёт название комнаты, как в приложении Dreame. Для своего названия выбери «Своё название».
Покрытие пола
Рисунок пола на карте, как в приложении. Робот учитывает его для «Уборки по направлению пола».
Мебель
Мебель на карте, как в приложении Dreame. Предметы, найденные роботом, с неизвестным типом показаны серым и сохраняются как есть. Нажми на предмет на карте: его можно двигать, поворачивать за ↻ и менять размер за ↘.
Резервные копии
Копия хранится на роботе (последние 10). Восстановление заменяет текущую карту копией через прошивку; настройки и порядок комнат агент возвращает сам. Робот должен стоять на базе.
Камера: поездка и патруль
Камера: поездка и патруль
Робот едет без уборки. «Поехать к точке» — одна точка, робот ждёт там. Патруль — до 20 точек по очереди с паузой 5 с, потом база. Любая команда движения прерывает патруль. Смотреть — в модуле камеры.
Расписание патрулей
Патруль запускает агент, только если робот стоит на станции без ошибки.
Код доступа к видео
Тот же код, что в приложении Dreame на странице камеры. С ним агент, как приложение, включает на роботе видеомониторинг («camera monitoring»), и робот ездит стрелками без мотора пылесоса. Без кода ручное управление выключено. Агент хранит только хеш кода.

История уборок
История уборок
Записывает агент: уборки, прошедшие пока он работает.
Фото питомцев
Гифки робот снимает сам, когда видит животное (настройка «Фото домашних животных»). Агент забирает их с робота, пока прошивка их не удалила, и хранит последние 200. Фото с пометкой «уборка» — препятствие «питомец» из истории уборок. Всё лежит только на роботе и открывается по токену.

Доступ
Доступ
Дополнительные токены для умного дома и других устройств. «Чтение» видит состояние и карту, «Управление» ещё и запускает команды. Установка модулей, обновление и настройки доступны только основному токену.
Новый токен
Встраивание страницы
Адреса, на которых другие страницы (например, панель Home Assistant) могут показать эту панель. По одному в строке: схема, адрес и порт, без пути, например https://ha.home:8123. Пусто — встраивание запрещено. Страница для встраивания: /?embed=1#token=… с токеном «Управление».

Вид панели
Хранится на агенте и действует на всех устройствах. Размер не меняется при увеличении карты.
Обновление агента

Установить новую версию
Файл агента для робота (Linux ARM64). Если новая версия не ответит в течение минуты, агент сам вернёт прежнюю.
Выключи, чтобы обновление прошивки не затёрло сервис, модули и защиту региона — агент обезвреживает загрузчик обновлений. Включай только для штатного обновления прошивки: оно сбрасывает рут.
Wi-Fi
Wi-Fi · Проверка сети…
Проверка сети…
WPA2-Personal или открытая сеть. Эта версия штатного адаптера поддерживает пароль из 8–63 символов ASCII без двойных кавычек и обратной косой черты.
После отправки настроек точка робота отключится. Подключись к домашней сети и открой новый IP робота на порту 8765. При неудаче агент запросит возврат точки доступа.
Журнал агента и модулей
Журнал агента и модулей
Последние 32 КБ: ошибки команд агента, его запуски, обновления и вывод модулей. Журнал агента лежит в памяти и очищается при перезагрузке робота.
Диагностика
Диагностика и ручной запрос
Модель, прошивка, хэши её файлов, аппаратная таблица и что из этого работает. Идентификатор робота в отчёт не попадает.
