Разделение и объединение комнат

Для разделения выбери комнату в списке, затем две точки линии на карте. Перед применением проверь параметры.

Пороги: проходимые и непроходимые
Зелёная линия — проходимый порог, красная — непроходимый. Выбери существующий порог или укажи две точки нового на карте.


Настройки
Настройки применяются только по нажатию кнопки.


Региональная блокировка
В этом режиме блокирующие вызовы device_lock игнорируются, включая ручную установку кода 401. Снятие блокировки кодом 200 остаётся доступно.
Статус ещё не получен
Меняет текущий статус через device_lock. Прошивка может изменить его повторно после проверки региона.
